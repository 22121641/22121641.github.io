Client side processing versus Server side processing

The difference between client side processing and server side processing is with client side processing when you type your username and password into the input file and click login java script code running in the browser can perform imidiate checks. Server side processing is where the server checks does this username exist and does the provided password match the stored password for that user. If they match the server generates a succesfull login sesion.
